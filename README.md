# Pickle-Balance

Website for Pickle-Balance — strength and balance coaching for pickleball players who are new to athleticism. Hosted on GitHub Pages at [picklebalance.co](https://picklebalance.co).

## Structure

- `index.html` — single-page site (Story, About Katy, Method, Who It's For, Classes, Contact)
- `css/style.css` — styling
- `js/main.js` — nav toggle + contact form submission
- `CNAME` — custom domain config for GitHub Pages

## Contact form

The contact form posts to a Formspree endpoint set in the `action` attribute of `#contactForm` in `index.html`. To change where submissions go, update or reconnect the form at [formspree.io](https://formspree.io).

## Local preview

Just open `index.html` in a browser — no build step required.
